# Changelog

All notable changes to this project are documented here.

## 1.0.0 — 2026-08-15

- Rebuilt the project as an installable Python package and CLI.
- Added real CSV/JSON generators for five academic figure families.
- Added exact output freshness checks and strict PDF/SVG/PNG validation.
- Made setup non-destructive and batch failures observable to automation.
- Added automated tests, multi-version CI, dependency updates, and release privacy checks.
- Replaced non-functional embedded-code templates with declarative input contracts.
